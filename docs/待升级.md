# Phase 1：Planner DAG 化（最高优先级）

## 目标

让 Planner 从：

> 决定调用哪些 Agent

升级为：

> 分解任务，并建立 Agent 之间的依赖关系

---

## 当前

类似：

```json
[
 {
  "agent":"knowledge"
 },
 {
  "agent":"analysis"
 }
]
```

问题：

没有表达：

* 为什么执行
* 输入是什么
* 输出给谁
* 哪些任务可以并行

---

## 修改后

Planner 输出任务图：

```json
{
 "goal":"分析销售下降原因",

 "tasks":[

 {
  "id":"task1",
  "agent":"knowledge",
  "objective":"获取2024销售数据"
 },

 {
  "id":"task2",
  "agent":"knowledge",
  "objective":"获取库存数据"
 },

 {
  "id":"task3",
  "agent":"analysis",
  "objective":"计算销量变化",
  "depends":["task1","task2"]
 }

 ]
}
```

---

## 涉及文件

新增：

```
models/task_graph.py
```

修改：

```
planner_agent.py

agent_orchestrator.py
```

---

## 收益

从：

```
固定流程
```

变成：

```
动态任务执行
```

这是 Multi-Agent 最核心升级。

# Phase 2：Agent Capability Registry（高优先级）

## 目标

解决未来 Agent 增加后的耦合问题。

现在：

Planner 知道：

```
Knowledge Agent
Analysis Agent
```

未来增加：

* SQL Agent
* Web Agent
* Code Agent

Planner 会越来越复杂。

---

## 新增：

```
AgentCapability
```

例如：

```python
class AgentCapability:

    name:str

    capabilities:list[str]

    input_types:list[str]

    output_types:list[str]
```

注册：

```python
KnowledgeAgent:

[
 "document_search",
 "fact_extraction"
]


AnalysisAgent:

[
 "calculation",
 "statistics"
]
```

Planner：

不再问：

> 调哪个 Agent？

而是：

> 我需要什么能力？

然后自动匹配。

---

## 文件：

新增：

```
core/agent_registry.py
models/capability.py
```

---
